# mean_reversion_v1 验证与激活路线

## 目标

在不使用历史旧权重作为兜底的前提下，得到一份可复现的候选策略报告。候选未通过或未
激活不阻塞 v0.8 发布，但机会榜必须明确不可用。

## 阶段

### R0 — 治理基础

- 实现 `ExperimentManifest` 和策略状态机。
- 为研究快照记录 Provider trace、复权、证券存续期、数据版本与哈希。
- 在代码和测试中禁止研究路径直接构建 Provider。

完成信号：fixture 实验能生成确定 manifest，非法状态迁移被拒绝。

### R1 — point-in-time 数据集

- 通过 Data Gateway 获取 2022-01-01 至 2026-07-31 数据。
- 按调仓日重建可交易证券池，覆盖退市/新股/停牌状态。
- 输出覆盖率、缺失类型和供应商降级统计，不提交原始 CSV/PKL。

完成信号：每期至少 500 只且总覆盖 ≥90%，否则实验直接 fail。

### R2 — 训练选择

- 只用 2022–2024 计算候选参数、方向和 IC_IR。
- 删除绝对相关性 >0.7 的冗余项。
- 按训练 IC_IR 归一权重并限制单因子 ≤35%。

完成信号：冻结 factor/config hash，之后不得用验证/OOS 调参。

### R3 — 验证与样本外

- 在 2025 validation 上检查方向、参数邻域和覆盖。
- 在 2026-01-01 至 2026-07-31 OOS 上评估 Rank IC、IC_IR、bootstrap 下界、
  Top20 20 日净超额与 40bp 成本。
- 运行未来数据泄漏和 point-in-time universe 审计。

完成信号：manifest 对每个门槛给出证据与 pass/fail。

### R4 — 人工批准与激活

- 全部门槛通过后将 draft 转为 validated。
- owner 阅读报告并执行 approve；批准不自动激活。
- owner 显式 activate，新榜单缓存键绑定策略/因子/数据日期/配置哈希。

完成信号：只有 active 版本能产生机会榜；退役后缓存不可串用。

## 停止条件

以下任一情况出现即停止晋升并保留失败报告：数据覆盖不足、样本池不是 point-in-time、
训练外调参、成本未计入、bootstrap 下界不为正、参数邻域不稳健或任一核心 OOS 门槛失败。
