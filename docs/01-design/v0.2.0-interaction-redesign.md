## 1. 问题分析

### 1.1 L0/L1/L2 有什么问题

| 问题 | 表现 |
|------|------|
| **含义不透明** | L0/L1/L2 对新人零信息量，必须看文档才知道区别 |
| **决策成本高** | 用户每次使用要先判断"我这是L0还是L1？" |
| **命令太长** | `diting l1 --symbols 002475 --engines vmd_rsi` 敲9个词才分析一只股票 |
| **参数太多** | `--symbols` `--engines` `--watchlist` `--notify` `--output` — 用户记不住 |
| **进阶用户被惩罚** | 想加个引擎也要敲全命令，没有递进体验 |

### 1.2 核心矛盾

```
用户想要的：                 工具提供的：
diting 002475                diting l1 --symbols 002475 --engines vmd_rsi
→ 告诉我好不好               → [vmd_rsi] 评分 50/100 · accumulate
```

用户打开谛听的唯一目的是 **"看一只股票"**，不是"选择分析层级"。

## 2. 设计原则

### 三条铁律

| # | 原则 | 说明 |
|:-:|------|------|
| 1 | **股票代码优先** | 第一参数永远是股票代码，不是命令名 |
| 2 | **结论先行** | 输出第一行告诉用户买不买，细节在后面 |
| 3 | **递进披露** | 不加参数=快速结论，加参数=更多细节 |

### 三不原则

- 不让用户选择分析层级
- 不让用户记住 `--symbols` 之类的 flag
- 不让用户看到 Python 技术术语

## 3. 命令结构

### 3.1 新命令树

```bash
diting <code>                  # 🎯 快速评估（80% 的使用场景）
diting <code> --more           #    详细分析
diting <code> --report         #    生成 HTML 报告

diting scan <code>             # 🔍 只看行情快照
diting compare A,B             # 🔄 对比多只股票
diting watchlist               # 📋 自选股概览

diting init                    # ⚙️ 首次配置
diting serve                   # 🌐 启动 Web 版
```

### 3.2 命令详解

#### 🎯 `diting 002475` — 快速评估（核心）

默认行为，什么都不加：

```bash
$ diting 002475
──────────────────────────────────────
 002475 · 立讯精密
 🟢 建议买入 · 评分 72/100
──────────────────────────────────────

看多理由：
  ① 周期触底 — 处于周期低位，反弹概率较大
  ② RSI 超卖 — RSI(14) 28.3，短期有修复动力
  ③ 资金流入 — 主力近 3 日净流入 +2.3 亿

看空理由：
  ① 估值偏高 — PE 30x，高于行业 25x
  ② 板块轮出 — 消费电子资金持续流出

──────────────────────────────────────
  $ diting 002475 --more    看详细分析
  $ diting 002475 --report  看完整报告
  $ diting serve            开网页版
──────────────────────────────────────
```

特点：
- **一行搞定**：`diting 002475` 就够了
- **第一眼就懂**：颜色 + emoji + 中文结论
- **有出口**：想知道更多？`--more` `--report` `serve`

#### 📄 `diting 002475 --report` — HTML 报告

生成完整 HTML 报告（内置 ECharts），存到当前目录：

```bash

📄 保存到 ./report-002475.html
```

### 3.3 保留但不显示的进阶选项

进阶用户仍然可以通过 --engine 指定引擎，但默认不展示：

```bash
# 默认行为（所有引擎跑一遍，取最佳结论）
diting 002475

# 进阶（指定引擎）
diting 002475 --engine wyckoff
diting 002475 --engine vmd_rsi,buffett
```

## 4. 交互流程

### 4.1 用户旅程（从安装到深度使用）

```
① 首次使用
   pip install diting
   diting init                → 引导输入 Key，完成配置

② 日常使用（80%）
   diting 002475              → 3 秒出结论

③ 进阶使用（15%）
   diting 002475 --more       → 看技术面、估值、资金
   diting compare A,B         → 对比两只股票

④ 深度使用（5%）
   diting 002475 --report     → 生成 HTML 报告
   diting serve               → 开 Web 分享
```

### 4.2 学习曲线

```
第1次用：diting 002475         → 懂了，看结论
第2次用：diting 002475 --more  → 发现还可以看细节
第3次用：diting compare ...    → 发现能对比
第4次用：diting serve          → 原来还能开网页

自然递进，不需要学，用到的自然就发现了。
```

## 5. 输出格式

### 5.1 颜色规范

| 场景 | 颜色 |
|------|:----:|
| 建议买入/评分≥75 | 🟢 绿 |
| 建议关注/评分55-74 | 🟡 黄 |
| 建议观望/评分35-54 | ⚪ 灰 |
| 建议回避/评分<35 | 🔴 红 |
| 涨跌幅正 | 绿色 |
| 涨跌幅负 | 红色 |

### 5.2 结论映射

| 评分 | 结论 | 含义 |
|:---:|:----:|------|
| ≥75 | 建议买入 | 多引擎一致看多 |
| 55-74 | 建议关注 | 中性偏多，可关注 |
| 35-54 | 建议观望 | 信号不明，等 |
| <35 | 建议回避 | 多引擎看空 |

### 5.3 错误提示

```bash
# 股票不存在
$ diting 999999
❌ 未找到股票 999999，请检查代码

# 数据不可用
$ diting 002475
⚠️ 暂时无法获取 002475 的数据，请稍后重试

# 网络问题
$ diting 002475
⚠️ 网络连接失败，检查网络后重试

# 没有配置
$ diting 002475
⚠️ 还没有配置数据源
  $ diting init    → 开始配置
```

## 7. 新旧对照

### 7.1 命令映射

| v0.1.0（旧） | v0.2.0（新） | 变化 |
|-------------|-------------|------|
| `diting l0 --symbols 002475` | `diting scan 002475` | 简化 |
| `diting l1 --symbols 002475 --engines vmd_rsi` | `diting 002475` | 零参数 |
| `diting l2 --symbols 002475 --engines all --output ./` | `diting 002475 --report` | 简化 |
| — | `diting 002475 --more` | 新增 |
| — | `diting compare A,B` | 新增 |
| `diting run --symbols 002475` | `diting 002475` | 合并 |
| `diting l0 --watchlist` | `diting watchlist` | 简化 |

### 7.2 参数变化

| 旧参数 | 新状态 | 说明 |
|-------|:-----:|------|
| `--symbols` | ❌ 移除 | 参数变成主参数 |
| `--engines` | 🔒 保留但隐藏 | 进阶用户用 `--engine` |
| `--watchlist` | ❌ 移除 | 变成子命令 `diting watchlist` |
| `--notify` | 🔒 保留 | cron 场景用 |
| `--output` | ❌ 移除 | `--report` 自动保存到当前目录 |
| `--json` | ❌ 移除 | 后续可按需加回 |

### 7.3 输出对比

旧版输出（v0.1.0）：
```

  [vmd_rsi] 评分 50/100 · accumulate
  无明显择时信号

```

新版输出（v0.2.0）：

  ② RSI 超卖 — 短期有修复动力

## 附录：反馈与讨论

### 关键决策记录

| 决策 | 选项 | 选择理由 |
|------|------|---------|
| 默认命令 | `diting <code>` vs `diting check <code>` | 少敲一个词的差别，类比 google.com 直接搜 |
| --more vs l1 | 参数 vs 子命令 | `--more` 更轻量，子命令会膨胀命令树 |
| compare | 新功能 vs 后续加 | 核心场景之一，"帮我看看A和B哪个好" |
| --report vs l2 | 参数 vs 子命令 | `--report` 语义明确，"给我一个文件" |

### 未解决的问题

- compare 多只时输出太长怎么办
- `--more` 信息密度如何控制
- Web 版是否需要用户登录（暂不需要）
