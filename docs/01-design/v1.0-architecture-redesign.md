# 谛听 v1.0 重构设计

> 从设计原理出发，决定每个模块的去留。

---

## 0. 设计原则

1. **数据即资产** — 数据的产生时间、来源、有效期是数据的元属性，每层必须显式传递
2. **错误不静默** — 每层必须向上报告失败原因，禁止 `except: pass`
3. **渲染即组合** — 前端页面 = 组件树，不是单体函数
4. **测试即文档** — E2E 测试描述用户行为，不光是代码覆盖

## 二、重构模块（保留骨架，改内脏）

### 2.1 API 响应信封 — `routes.py` `_api_response()`

**保留：** `{server_time, cache_state, data}` 三字段结构  
**修改：** 新增 `freshness` 字段，改 `cache_state` 语义

```python
# 旧
{server_time: "2026-07-17T02:05:20Z", cache_state: "stale", data: {...}}

# 新
{
    server_time: "2026-07-17T02:05:20Z",  # 服务器响应时间
    data: {...},
    freshness: {                           # 新增
        data_time: "2026-07-17T01:55:00Z", # 数据产生时间
        source: "mx-data",                 # 数据来源
        is_fresh: false,                   # 是否新鲜
        age_seconds: 620,                  # 数据年龄
    }
}
```

**关键改动：** `cache_state` 不再由 service 层通过 dict 魔术字段 `_cache_state` 传递，改为 route 层从 `FreshnessInfo` 推导。

### 3.2 前端页面数据流（新规范）

```
page.js: render()
  → FreshnessIndicator.show(skeleton)
  → DataFetcher.fetch(url)
      ├→ cacheManager.getStale(key) → renderStale(data)
      ├→ api.xxx() → FreshnessTracker.record(data)
      └→ renderFresh(data)
```

每个页面的 `render()` 函数遵循同一模式：
1. 显示 skeleton
2. 尝试从缓存读取
3. API 请求
4. 渲染数据（含 freshness bar）
5. 写入缓存

## 四、新增基础设施

### 4.1 FreshnessTracker（后端）

```python
# src/diting/data/freshness.py
from dataclasses import dataclass
from datetime import datetime

@dataclass
class FreshnessInfo:
    data_time: datetime | None      # 数据产生时间
    source: str                     # 来源
    ttl_seconds: int                # 有效期
    cached_at: datetime             # 缓存时间

    @property
    def is_fresh(self) -> bool:
        if self.data_time is None:
            return False
        return (datetime.now() - self.data_time).total_seconds() < self.ttl_seconds

    @property
    def age_seconds(self) -> float:
        if self.data_time is None:
            return -1
        return (datetime.now() - self.data_time).total_seconds()
```

### 4.2 FreshnessBar（前端）

```javascript
// components/freshness.js
export function renderFreshnessBar(freshness) {
    const {data_time, source, is_fresh, age_seconds} = freshness;
    if (!data_time) return '';
    const cls = is_fresh ? 'fresh' : (age_seconds > 3600 ? 'stale' : 'warn');
    const label = is_fresh ? '实时' : `${Math.floor(age_seconds/60)}分钟前`;
    return `<div class="freshness-bar ${cls}">📡 ${label} · ${source}</div>`;
}
```
