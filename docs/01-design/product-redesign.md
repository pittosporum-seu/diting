# 谛听 · 产品重构设计

> 目标用户：有技术基础但不懂算法的散户
> 核心问题："我该不该买这只股票？"
> 产品形态：CLI（可折腾）+ Web（快速上手）

---

## 一、用户故事

### 场景A：小白朋友问"帮我看看002475怎么样"

```
当前方案：
  1. 打开谛听网页 → 输入002475
  2. 看到：「立讯精密 🟢 建议买入」
  3. 下面跟着：评分78分 · 估值偏低 · 技术面触底 · 资金流入
  4. 再往下：交互式K线图 + RSI指标

全程不需要理解VMD、Wyckoff、共识引擎。
```

### 场景B：你自己想深挖

```
diting 002475
→ 结论：建议买入（评分72/100）
→ 看多理由：VMD谷底反弹 · RSI超卖 · 主力资金连续3日流入
→ 看空理由：PE偏高(30x) · 板块轮动风险

diting l2 002475 --out report.html
→ 完整HTML报告，引擎级拆解，“为什么给了这个分”
```

## 二、CLI 层设计

### 2.1 命令简化

```bash
# 日常用（一行搞定）
diting 002475                  # 默认模式：结论先行
diting 002475,603659           # 对比分析

# 进阶用（保留现有能力）
diting l1 002475               # 标准分析
diting l2 002475               # 深度分析 + HTML报告
diting init                    # 首次引导（配key）
diting watchlist               # 看自选股
diting serve                   # 启动网页版
```

### 2.2 输出格式：结论先行

```
──────────────────────────────────────
 002475 · 立讯精密
 🟢 建议买入 · 评分 72/100 · 信心中等
──────────────────────────────────────

看多理由（3）：
  ① VMD周期位置 0.15 — 接近谷底，反弹概率大
  ② RSI(14) 28.3 — 超卖区间，短期有修复动力
  ③ 主力资金近3日净流入 +2.3亿

看空理由（2）：
  ① PE 30x，高于行业均值25x
  ② 消费电子板块近期资金轮出

报告 → diting l2 002475 --html
网页 → http://localhost:8080/stock/002475
──────────────────────────────────────
```

关键变化：
- **第一行就告诉结论**，不是 `[vmd_rsi] 50/100 · accumulate`
- **中文、颜色、emoji**，一眼看懂
- **渐进式信息披露**：想看技术指标？跑 `l2`
- **看多/看空理由并行**，用户自己判断

### 2.3 CLI 红绿色方案

| 评分 | 显示 | 颜色 |
|:---:|------|:----:|
| ≥75 | 🟢 建议买入 | 绿色 |
| 55-75 | 🟡 建议观望 | 黄色 |
| <55 | 🔴 建议回避 | 红色 |

## 四、引擎层改动

### 4.1 新增"结论引擎"

现在的架构是5引擎各自评分 → 共识融合。缺一个**从评分到"买不买"的翻译层**。

```
                  ┌─────────────────────┐
各引擎评分 →      │   VerdictEngine     │ → 结论 + 理由
                  │  （新增）           │
                  │  - 综合评分 → 买/卖  │
                  │  - 提取top3看多理由  │
                  │  - 提取top3看空理由  │
                  │  - 信心评分          │
                  └─────────────────────┘
```

这个引擎的本质：**把技术指标翻译成人话。**

| 指标 | 翻译 |
|------|------|
| VMD周期0.987 | `当前处于周期高位，短期回调风险较大` |
| RSI 28.3 | `RSI超卖，短期有修复动力` |
| 主力净流入2.3亿 | `主力资金近3日持续流入，有资金支撑` |
| PE分位78% | `估值处于历史高位` |

### 4.2 数据流

```
股票代码
  → 数据获取（mx-data / akshare）
    → 信号计算（RSI/VMD/技术指标）
      → 引擎分析（5引擎并行）
        → 共识融合
          → VerdictEngine（新增）
            → CLI输出（结论+理由）
            → 或
            → Web渲染（FastAPI + ECharts）
```

## 七、一句话总结

> **核心不是让用户理解引擎是怎么算的，而是让用户在3秒内知道：该不该买，为什么。**

CLI给"想折腾的人"一个后门去看引擎细节，Web给"不想折腾的人"一个入口快速拿结论。底层引擎不变，变的是**展示层和翻译层**。🐾
