> 日期：2026-07-07 | 版本：v0.3.0 | 状态：设计阶段 🟡

---

## 一、产品定位

### 一句话

**面向有技术背景但不想记命令的散户，打开网页输入股票代码，3 秒内知道该不该买、为什么。**

### 用户画像

| 角色 | 背景 | 需求 | 使用频率 |
|------|------|------|:-------:|
| **散户A** | 懂K线但不懂算法 | "帮我看看002475" | 每日 |
| **散户B** | 完全小白 | "哪个股票值得买" | 每周 |
| **海桐自己** | 懂算法但嫌CLI不方便 | "快速看一眼持仓" | 盘中多次 |

### 核心原则

1. **结论先行** — 第一眼看到的是买/卖/持有结论，不是数据
2. **递进披露** — 不加参数=快速结论，向下滚动=更多细节
3. **差异化体现** — VMD周期、多引擎共识、多空理由并列，别人没有

## 二、页面结构

### 导航

```
🐾 谛听    📊 仪表盘 | 🔍 个股分析 | 🎯 选股机会 | 📋 自选股 | ⚙️ 设置
```

### 页面清单

| # | 页面 | URL | 核心功能 | 数据来源 |
|:-:|:-----|:----|:---------|:--------|
| 1 | 仪表盘 | `/` | 大盘状态、持仓快照、最近信号 | Config + 持仓 CSV |
| 2 | 个股分析 | `/stock/{code}` | 结论卡、多空理由、K线+VMD、引擎评分、技术指标 | Pipeline |
| 3 | 选股机会 | `/opportunities` | 全市场扫描、评分排序、信号筛选 | Scan 引擎 |
| 4 | 自选股 | `/watchlist` | 批量评分、涨跌颜色、排序 | Watchlist CSV |
| 5 | 设置 | `/settings` | 数据源、AI模型、通知 | Config |

## 三、页面详细设计

### 3.1 📊 仪表盘 `/`

**用途：** 用户打开谛听的第一眼，快速了解大盘状态和自己的持仓。

**布局：**

```
┌────────────┬────────────┬────────────┬────────────┐
│  大盘今日    │  综合信号    │  持仓看多    │  今日持仓   │
│  +2.3%     │  68分       │  6/9 只     │  -3.2%     │
└────────────┴────────────┴────────────┴────────────┘

┌──────────────────────┬──────────────────────┐
│  大盘 VMD 周期位置     │  持仓评分分布          │
│  [仪表盘图]           │  [饼图]              │
└──────────────────────┴──────────────────────┘

┌──────────────────────┬──────────────────────┐
│  最近信号              │  市场情绪             │
│  立讯精密  VMD谷底 强度 │  😐 中性偏谨慎       │
│  五洲新春  MACD金叉     │  成交量萎缩12%       │
│  ...                  │                      │
└──────────────────────┴──────────────────────┘
```

**数据加载策略：**
- 大盘指数：从数据源获取最新点位和涨跌幅
- 持仓数据：从 `config/watchlist.csv` 或 `current_holdings.csv` 加载
- 信号：缓存最近分析结果，不实时拉取

**API：**
```
GET /api/dashboard
→ { market_index, signal_score, holdings_summary, recent_signals }
```

### 3.3 🎯 选股机会 `/opportunities`

**用途：** 从全市场自动筛出值得关注的股票。

**布局：**

```
┌──────────────┬──────────────┬──────────────┬──────────────┐
│  VMD 谷底     │  RSI 超卖    │  RSI 超买    │  VMD 峰顶    │
│  23 只        │  18 只       │  12 只       │  4 只        │
└──────────────┴──────────────┴──────────────┴──────────────┘

┌─ 综合评分 ≥ 75（建议关注）────────────────────────┐
│  代码    名称     评分  结论    VMD    RSI    资金    │
│  002475  立讯精密  78   🟢买入  谷底   超卖   流入    │
│  603659  璞泰来    72   🟡关注  低位   中性   流入    │
│  600519  贵州茅台  68   🟡关注  中位   中性   平稳    │
│  300750  宁德时代  55   ⚪观望  高位   超买   流出    │
└──────────────────────────────────────────────────────┘
```

**筛选条件：**
- 三维评分 ≥ 30
- 或 VMD 谷底 (<0.2)
- 或 RSI 超卖 (<30)
- 或 主力资金流入 > 1000万

**API：**
```
GET /api/opportunities?sort=score&min_score=30
→ { counts: {vmd_trough, rsi_oversold, ...}, stocks: [...] }
```

### 3.5 ⚙️ 设置 `/settings`

**用途：** 让用户不碰代码就能调整策略。

| 分组 | 可配置项 | 选项 |
|------|---------|------|
| 数据源 | 优先数据源 | eltdx / ashare / mx-data / akshare |
| 数据源 | 降级策略 | 自动 / 固定 |
| AI模型 | 分析模型 | DeepSeek V4 Pro / Flash / MiMo |
| AI模型 | API Key | 输入框 |
| 分析 | 默认层级 | 快速 / 详细 / 深度 |
| 分析 | 启用引擎 | 6引擎多选开关 |
| 通知 | 推送渠道 | 本地 / 飞书 / 邮件 |
| 通知 | 条件提醒 | VMD谷底 / RSI超卖 / 大盘暴跌 |

**数据持久化：** 写入 `config/diting.yaml` + `.env`

## 五、技术选型

| 层 | 方案 | 理由 |
|:---|:-----|:------|
| 后端框架 | **FastAPI**（已有） | `diting serve` 已实现，直接复用 |
| 模板引擎 | **Jinja2**（已有） | 现有模板系统，无需额外依赖 |
| 图表 | **ECharts 5.5.0** | 309KB轻量，iPad兼容，已内联在项目中 |
| 前端 | **HTML + CSS + JS** | 不依赖 npm/node，单文件可运行 |
| 部署 | `diting serve` | 单进程，无数据库依赖 |
| 配色 | 浅色主题 | 金融用户习惯。参考 Linear.app 风格 |

### 实现策略

**首页搜索页：** 已有（`search.html`）
**结果页：** 已有（`result.html`），需要把原型的 ECharts 和样式搬过去
**仪表盘/选股/设置：** 新增页面模板

## 七、与 CLI 的关系

```
        同一套引擎
       ┌────┴────┐
      CLI         Web
  diting 002475   打开浏览器
  → 终端输出       → 图形界面
  → 可自动化       → 可分享
  → 可调参数       → 零门槛
```

- CLI 和 Web 共享 `Pipeline` / `Engine` / `ConfigLoader` 等核心模块
- Web 是 CLI 的**前端包装**，不重复实现分析逻辑
- 新引擎/新数据源上线后，CLI 和 Web 同时受益
