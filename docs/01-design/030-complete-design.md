## 三、用户旅程图

### 3.1 场景 1：首次使用

```
用户 ├─ 安装: pip install diting
     ├─ 启动: diting serve
     ├─ 打开浏览器 → localhost:8000
     ├─ 看到仪表盘（空数据）
     ├─ 点击"设置"
     ├─ 配置数据源（选 eltdx，免费默认）
     ├─ 配置 AI 模型（可选）
     ├─ 回到仪表盘 → 看到默认数据
     └─ 输入"002475" → 看到分析结论

时间线: ─────●─────●─────●─────●──────●──────●
        启动   仪表盘  设置  配数据源  回首页  分析
```

### 3.2 场景 2：快速看一眼（核心场景）

```
用户 ├─ 打开谛听
     ├─ 仪表盘 → 看一眼大盘状态（3秒）
     ├─ 点"自选股" → 看持仓评分变化（5秒）
     │   五洲新春 81 🟢 ← 继续持有
     │   金科ETF  35 🔴 ← 问题信号
     ├─ 点"金科ETF" → 看详细分析（10秒）
     └─ 关闭

总耗时: ────●───────────●─────────────●───→
        3s仪表盘    5s自选股     10s个股分析
```

### 3.3 场景 3：深度研究

```
用户 ├─ 输入 002475
     ├─ 看结论卡 → 建议买入 78分（2秒）
     ├─ 看多空理由 → 3个看多 vs 2个看空（5秒）
     ├─ 看K线图 → 拖拽缩放看走势（15秒）
     ├─ 看引擎评分 → 6引擎各自打分（5秒）
     ├─ 看技术指标 → RSI/MACD/VMD 状态（5秒）
     ├─ 点"--report" → 生成HTML报告
     └─ 分享报告给朋友

总耗时: ──●────●───────●───────●───────●─────●──→
        结论卡 多空理由  K线    引擎评分  指标   报告
```
