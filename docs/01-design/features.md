## 产品定位

**谛听** — A股多模型AI投资分析工具。聆听市场多维度信号，用多种分析流派交叉验证，输出可操作的交易决策建议。

- 独立 Python 库，`pip install diting` 即用
- CLI + Python API 双接口
- 三档启动层级（L0/L1/L2），适应不同场景

## 数据源

### 妙想金融数据 (mx-data) — 主力数据源

基于东方财富权威数据库，通过自然语言查询获取以下数据：

| 数据类型 | 查询示例 | 应用层 |
|---------|---------|--------|
| 实时行情 | `002475 收盘价 涨跌幅 成交量` | L0/L1/L2 |
| 历史日线 | `002475 每日收盘价 开盘价 最高价 最低价 成交量` | L1/L2 信号计算 |
| 财务数据 | `002475 近三年净利润 营业收入 ROE` | L2 基本面引擎 |
| 资金流向 | `002475 主力资金流向 DDX DDY` | L2 资金面分析 |
| 股东信息 | `002475 十大股东 机构持股` | L2 深度调研 |

**使用约束：**
- 需配置 `MX_APIKEY` 环境变量（[获取地址](https://dl.dfcfs.com/m/itc4)）
- 个股和 ETF **必须分开查询**（混查会导致 ETF 数据被截断）
- 批查询每批 **不超过 4 只**
- 历史查询需加 `"每日"` 前缀以获取日线数据

### 降级链

```
mx-data (妙想，主力) → akshare (免费兜底) → SQLite 本地缓存
```
