# 谛听 · 功能设计

> 版本：v1.0 | 日期：2026-07-04 | 状态：设计阶段

---

## 产品定位

**谛听** — A股多模型AI投资分析工具。聆听市场多维度信号，用多种分析流派交叉验证，输出可操作的交易决策建议。

- 独立 Python 库，`pip install diting` 即用
- CLI + Python API 双接口
- 三档启动层级（L0/L1/L2），适应不同场景

## L0/L1/L2 场景映射

| 场景 | 推荐层级 | 典型执行时间 | 说明 |
|------|---------|------------|------|
| 盘中快速扫一眼 | L0 | <5s | 只看持仓价格和涨跌 |
| 盘前速报 | L1 | 30-60s | AI 辅助解读 + 信号提示 |
| 收盘持仓分析 | L1 | 60-90s | 完整信号 + 1-2个引擎 |
| 周末深度复盘 | L2 | 3-5min | 全部引擎 + 多报告交付 |
| 个股深度调研 | L2 | 2-4min | 指定单只 + 全部引擎 |
| GitHub Actions 自动 | L1/L2 | 按 cron | 无需人工触发 |

## 非功能需求

| 需求 | 目标 | 度量 |
|------|------|------|
| L0 响应时间 | <5秒 | 单只持仓行情快照 |
| L1 响应时间 | <90秒 | 5只标的 + 2个引擎 |
| 数据可用性 | 99% | 降级链覆盖率 |
| AI 超时容错 | 引擎挂 ≠ 报告挂 | 跳过失败引擎继续 |
| 离线可用 | L0 完全离线 | akshare 本地数据 |
| iPad 兼容 | HTML 报告完全可用 | ECharts 轻量版 |
