# 谛听 v0.1.0 后端设计

> 前端是薄客户端。后端承载所有业务逻辑、数据新鲜度保证、错误处理。
> 本设计覆盖：用户流程 → API 契约 → 数据架构 → 测试规则。

---

## 一、用户流程（从后端视角）

### 1. 打开应用 → 仪表盘

```
用户操作: 访问首页
后端流程:
  1. GET /api/health          → 检查服务存活
  2. GET /api/dashboard       → 获取仪表盘数据
     ├── 大盘指数（上证/深证/创业板）
     ├── 市场情绪（涨跌方向）
     ├── 自选股概览（数量 + Top 涨跌）
     ├── 选股机会统计（买入/关注/避开数量）
     └── VMD 周期位置（可选）

预期: < 2s 返回，数据新鲜度明确标注
```

### 2. 搜索股票

```
用户操作: 输入代码/名称
后端流程:
  1. GET /api/stock-search?q=000001
     ├── 本地股票列表匹配（< 10ms）
     └── 模糊搜索（代码/名称/拼音）
  2. GET /api/stock-list       → 全市场列表（首次加载时）

预期: < 100ms 返回匹配列表
```

### 3. 查看个股详情

```
用户操作: 点击股票
后端流程:
  1. GET /api/stock/{code}
     ├── 实时行情（价格/涨跌/PE/PB）
     ├── 历史日线（250天）
     ├── K 线数据（OHLCV + 均线/布林）
     ├── 技术指标（RSI/MACD/KDJ/VWAP）
     ├── 引擎评分（wyckoff/buffett/canslim/volume_profile/vmd_rsi）
     ├── 综合评分 + 评级
     ├── 多空理由
     └── 资金流向（可选）

预期: < 30s 返回完整分析（含 AI 引擎），< 5s 返回纯计算
```

### 4. 管理自选股

```
用户操作: 添加/删除自选股
后端流程:
  1. POST /api/watchlist {code, name, market}
     → 写入 watchlist.csv + 验证股票存在
  2. GET /api/watchlist
     → 返回列表 + 实时行情（每只）
  3. DELETE /api/watchlist/{code}
     → 从 watchlist.csv 移除

预期: < 2s 返回
```

### 5. 查看选股机会

```
用户操作: 查看机会页
后端流程:
  GET /api/opportunities
    ├── 全市场扫描（后台任务，按批次）
    ├── 每只 quick_score → buy/watch/avoid 分类
    └── 返回 Top N + 统计

预期: < 1s 返回缓存结果，后台异步刷新
```

### 6. 管理设置

```
用户操作: 修改设置
后端流程:
  1. GET /api/settings
     → 返回 {provider_toggles, engine_toggles, ai_model}
  2. POST /api/settings {engine_wyckoff: "0", ai_model: "..."}
     → 持久化到 SQLite

预期: < 100ms 返回
```

## 三、数据架构

### 3.1 层间数据协议

```
Provider.fetch()
  → RawData (provider 原始数据 + fetch_timestamp)

Repository.get_xxx()
  → DomainData (标准化 dataclass + provider_info)

Cache Layer
  → CachedData = DomainData + cached_at + expires_at

Service.get_xxx()
  → ServiceResult = {
      data: DomainData,
      freshness: FreshnessInfo,
      meta: {cache_level, response_time_ms}
    }

Router
  → APIResponse = ServiceResult → JSON + error handling
```

### 3.2 FreshnessInfo 定义

```python
@dataclass
class FreshnessInfo:
    data_time: datetime | None    # 数据产生时间
    source: str                   # 来源标识
    is_fresh: bool                # 是否在有效期内
    age_seconds: float            # 已过秒数
    ttl_seconds: int              # 有效期

    @classmethod
    def from_provider(cls, fetch_result, ttl: int):
        return cls(
            data_time=fetch_result.timestamp,
            source=fetch_result.provider_name,
            is_fresh=(datetime.now(UTC) - fetch_result.timestamp).seconds < ttl,
            age_seconds=(datetime.now(UTC) - fetch_result.timestamp).seconds,
            ttl_seconds=ttl,
        )

    @classmethod
    def from_cache(cls, cached_at: datetime, ttl: int, source: str):
        age = (datetime.now(UTC) - cached_at).total_seconds()
        return cls(
            data_time=cached_at,
            source=f"cache({source})",
            is_fresh=age < ttl,
            age_seconds=age,
            ttl_seconds=ttl,
        )
```

### 3.3 错误分类

```python
class ErrorCode(enum.StrEnum):
    DATA_UNAVAILABLE = "DATA_UNAVAILABLE"   # 所有数据源不可用
    PROVIDER_TIMEOUT = "PROVIDER_TIMEOUT"   # 单个数据源超时
    NOT_FOUND = "NOT_FOUND"                 # 股票不存在
    INVALID_PARAM = "INVALID_PARAM"         # 参数格式错误
    AI_ENGINE_ERROR = "AI_ENGINE_ERROR"     # AI 引擎异常
    CACHE_ERROR = "CACHE_ERROR"             # 缓存读写异常
    INTERNAL_ERROR = "INTERNAL_ERROR"       # 未分类内部错误
```

## 四、测试规则

### 4.1 后端测试分层

```
Layer 0: 单元测试
  ├── Provider: mock 外部 API，验证 fetch/parse/error
  ├── Cache: 验证 L1/L2 读写、TTL 过期、db_get 边界
  ├── Service: mock 下层依赖，验证业务逻辑
  └── Schema: 验证 dataclass 序列化/反序列化

Layer 1: 集成测试
  ├── Provider → Repository 降级链
  ├── Service → Cache 新鲜度传递
  └── Router → Service 错误传播

Layer 2: E2E 测试（API 级别）
  ├── 启动 uvicorn → 用 httpx 调所有端点
  ├── 验证每个端点的 200/4xx/5xx 响应
  └── 验证 freshness 字段完整性

Layer 3: E2E 测试（浏览器级别）
  └── Playwright → 真实页面渲染验证（Phase 3 再做）
```

### 4.3 性能约束

| 端点 | P50 | P95 | 备注 |
|------|-----|-----|------|
| health | < 10ms | < 50ms | 纯内存 |
| stock-search | < 50ms | < 200ms | 内存列表匹配 |
| settings GET | < 50ms | < 200ms | SQLite 读 |
| settings POST | < 50ms | < 200ms | SQLite 写 |
| watchlist GET | < 500ms | < 2s | 需获取实时行情 |
| dashboard GET (缓存) | < 100ms | < 500ms | L1/L2 命中 |
| dashboard GET (刷新) | < 5s | < 15s | 含全市场扫描 |
| stock GET (纯计算) | < 2s | < 5s | 不含 AI 引擎 |
| stock GET (全引擎) | < 30s | < 60s | 含 AI 引擎 |
| opportunities (缓存) | < 100ms | < 500ms | 后台异步刷新 |
