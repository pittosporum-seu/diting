# Task 21 — v0.8 CLI

## Goal

Replace the legacy level/quick-score CLI with a small breaking command surface that invokes the
same facade, gateway, orchestrator and strategy registry as the other v0.8 interfaces.

## Contract

- Canonical commands are `analyze`, `quote`, `scan`, `compare`, `watchlist`, `strategy` and `serve`.
- A six-digit first argument maps only to `analyze CODE --profile standard`.
- `l0`, `l1`, `l2`, `run` and the legacy `init` wizard fail with `CLI_COMMAND_REMOVED`.
- `quote` and `compare` call the cached data gateway through `Diting.get_quote`; they never analyze.
- `scan` calls `Diting.scan` and fails explicitly when the selected strategy is not active.
- `watchlist` uses typed durable records and audits local mutations; it no longer reads a CSV as
  production state.
- `strategy` reports the selected/active registry version and cannot silently activate one.
- `serve` pins one uvicorn worker.
- JSON output serializes the same immutable domain contracts returned by the Python API.

## Verification

- Click command inventory, version/help and six-digit routing.
- Profile/freshness/force-refresh propagation with injected facade doubles.
- Quote-only compare, active scan, watchlist CRUD/audit and strategy state.
- Removed command matrix and `serve --help` without runtime bootstrap.
- Full non-network tests, Ruff, formatting and pre-commit.
