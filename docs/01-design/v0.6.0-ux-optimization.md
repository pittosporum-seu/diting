> 基于海桐反馈的 4 个问题 | 2026-07-11
> 核心思路：缓存优先、体验为先

## 问题 1：首页加载慢（"正在获取信号"）

**现象：** 每次进主页都要等待 API 返回数据，期间一直显示"正在获取信号"。

**方案：两级渲染（Cache-First Render）**

```
首次访问：
  localStorage 无缓存
  → 显示骨架屏
  → 调 API 获取数据
  → 渲染 + 存入 localStorage

再次访问（5分钟内）：
  localStorage 有缓存
  → 立即用缓存数据渲染（0ms 等待）
  → 后台静默调 API 获取最新数据
  → 有新数据则渲染替换（平滑过渡，不闪屏）
```

**具体改动：**

1. `app.js` 新增 `cacheManager` 模块：
```javascript
const cacheManager = {
  // localStorage key 前缀
  PREFIX: 'diting_cache_',
  // 默认 TTL 5 分钟
  TTL: 5 * 60 * 1000,

  get(key) {
    const raw = localStorage.getItem(this.PREFIX + key);
    if (!raw) return null;
    const { data, ts } = JSON.parse(raw);
    if (Date.now() - ts > this.TTL) {
      localStorage.removeItem(this.PREFIX + key);
      return null;
    }
    return data;
  },

  set(key, data) {
    localStorage.setItem(this.PREFIX + key, JSON.stringify({ data, ts: Date.now() }));
  },

  clear() { /* 清空所有 diting 缓存 */ }
};
```

2. `renderDashboard()` 改为：
```javascript
async function renderDashboard() {
  // Phase 1: 尝试从缓存加载
  const cached = cacheManager.get('dashboard');
  if (cached) {
    _renderDashboardHTML(cached);  // 直接渲染（同步）
  } else {
    _renderSkeleton();             // 骨架屏
  }

  // Phase 2: 后台拉取实时数据
  try {
    const res = await api.dashboard();
    if (res.ok) {
      cacheManager.set('dashboard', res.data);
      _renderDashboardHTML(res.data);  // 更新渲染
    }
  } catch (_) {
    if (!cached) showErrorBanner();  // 无缓存时才报错
  }
}
```

3. 同理处理 `watchlist`、`opportunities` 等页面（统一模式）

**注意：** 这个模式也叫 **stale-while-revalidate** — 先显示旧的，后台验证新的。效果：0ms 白屏。

## 问题 2：移动端模块太宽

**现象：** 手机上每个 stat-card 独占一行，横向非常宽，阅读效率低。

**当前 CSS（@480px）：**
```css
.stat-grid { grid-template-columns: 1fr; }
```

**方案：自适应 Grid**

```
手机（<480px）:
  大盘指数：2列（3个指数默认铺不满，auto-fit 自动居中）
  信号卡片：2列
  其他卡片：全文宽度（保持可读性）

平板（480-768px）:
  大盘指数：3列
  信号卡片：4列
  其他卡片：全文宽度

桌面（>768px）:
  大盘指数：3列
  信号卡片：4列
  其他卡片：全文宽度
```

```css
/* 手机 — 更紧凑的网格 */
@media (max-width: 480px) {
  #dash-indices {
    grid-template-columns: repeat(3, 1fr);  /* 指数三列 */
    gap: 8px;
  }
  #dash-indices .stat-card {
    padding: 12px 8px;          /* 更紧凑的内边距 */
  }
  #dash-indices .stat-value {
    font-size: 20px;            /* 更小的字号 */
  }

  #dash-signals {
    grid-template-columns: repeat(2, 1fr);  /* 信号卡片两列 */
    gap: 8px;
  }
  #dash-signals .stat-card {
    padding: 12px 8px;
  }
  #dash-signals .stat-value {
    font-size: 22px;
  }

  .stat-grid:not(#dash-indices):not(#dash-signals) {
    grid-template-columns: 1fr;  /* 其他 grid 保持单列 */
  }
}
```

**效果：** 手机上指数3列显示，信号2列，卡片更紧凑不浪费宽度。

## 问题 3：缓存机制（每 5 分钟刷新）

**现状：** 服务端已有 `cache.py`（TTLCache），但前端完全没有缓存，每次页面切换都重新请求。

**方案：浏览器端 localStorage 缓存 + 服务端缓存增强**

### 3.1 前端缓存（新）

在 `api.js` 或 `app.js` 中统一封装：

```javascript
// api.js 增强：添加缓存层
async function _requestWithCache(method, path, body, cacheKey, ttl = 5 * 60 * 1000) {
  // GET 请求才走缓存
  if (method === 'GET' && cacheKey) {
    const cached = cacheManager.get(cacheKey);
    if (cached) return { ok: true, data: cached, fromCache: true };
  }

  const result = await _request(method, path, body);
  if (result.ok && method === 'GET' && cacheKey) {
    cacheManager.set(cacheKey, result.data);
  }
  return result;
}
```

缓存键映射：

| 接口 | 缓存 Key | TTL |
|:----|:---------|:---:|
| GET /dashboard | `dashboard` | 5min |
| GET /watchlist | `watchlist` | 5min |
| GET /opportunities | `opportunities` | 5min |
| GET /market-sentiment | `market_sentiment` | 5min |
| GET /stock/{code} | `stock_{code}` | 2min |
| GET /settings | `settings` | 10min |

### 3.2 服务端缓存增强（可选）

当前 `cache.py` 的 TTL：
- 实时行情：30s（太短，建议 → 2min）
- 历史 K 线：5min（合理）
- 个股分析：2min（合理）

只改实时行情 TTL（`_realtime_cache` 从 30s → 120s）。

## 问题 4：全市场股票名称/代码搜索

**现状：** 输入 6 位代码才能搜索，不支持名称模糊搜索。

**方案：全市场股票列表缓存 + 模糊搜索下拉**

### 4.1 数据来源

方案 A（推荐）：服务端启动时生成 `stock_list.json`，通过 API 提供
```python
# 新增 endpoints:
# GET /api/stock-list → 返回全市场股票 [{code, name, market}]
# 数据源：mx-data 或内置的 A 股股票列表（约 5000+ 只）
```

方案 B：内置静态 JSON（服务端本地缓存，首次请求时生成）

### 4.2 前端搜索框改造

```javascript
// 搜索输入框增强
function _initSearchWithSuggestions(inputEl) {
  const dropdown = document.createElement('div');
  dropdown.className = 'search-dropdown';
  inputEl.parentNode.appendChild(dropdown);

  let debounceTimer = null;

  inputEl.addEventListener('input', () => {
    clearTimeout(debounceTimer);
    const q = inputEl.value.trim();
    if (q.length < 1) { dropdown.innerHTML = ''; return; }

    debounceTimer = setTimeout(async () => {
      // 1. 先查本地缓存
      const stockList = await _getStockList();  // 全市场列表
      const matches = stockList.filter(s =>
        s.code.includes(q) || s.name.includes(q) || s.pinyin?.includes(q)
      ).slice(0, 8);

      // 2. 渲染下拉
      dropdown.innerHTML = matches.map(s => `
        <div class="search-item" data-code="${s.code}">
          <span class="search-code">${s.code}</span>
          <span class="search-name">${s.name}</span>
        </div>
      `).join('');

      // 3. 点击选择
      dropdown.querySelectorAll('.search-item').forEach(el => {
        el.addEventListener('click', () => {
          inputEl.value = el.dataset.code;
          dropdown.innerHTML = '';
          inputEl.dispatchEvent(new Event('change'));
        });
      });
    }, 200);  // 200ms 防抖
  });

  // 点击外部关闭下拉
  document.addEventListener('click', (e) => {
    if (!e.target.closest('.search-bar')) dropdown.innerHTML = '';
  });
}
```

## 验证标准

- 首次访问仪表盘：骨架屏 → 数据加载 → 渲染
- 再次访问仪表盘（5分钟内）：秒开（无骨架屏）→ 2s 后刷新为最新数据
- 手机端指数卡片 3 列显示，信号卡片 2 列显示

- 缓存过期后自动拉取最新数据
- `pytest` 全部通过 + `ruff clean`
