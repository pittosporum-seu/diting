# v0.7.2 前端循环依赖修复

## 问题

两个 bug 叠加：

1. **循环依赖**: `app.js → router.js → pages/dashboard.js → app.js`
   → ES 模块加载时 `app.js` 的 exports 尚未就绪 → `state`/`showStatus` 等为 undefined

2. **DOMContentLoaded 竞态**: HTML 太小→瞬间解析完→事件早于外部模块下载触发
   → `app.js` 监听注册时事件已过 → 已修 (readyState)

## 加载时序

```
本地 (localhost:8100): 文件 0ms 延迟 → 模块在 DOMContentLoaded 前全部就绪 → 偶尔能过
VPS (HTTPS): 12 个模块逐个 fetch → DOMContentLoaded 提前触发 + 循环依赖 undefined → 白屏
```

## 修复设计

```
                    ┌─────────────────────┐
                    │       core.js        │  (新文件)
                    │ state, updateState   │
                    │ showStatus, _render  │
                    │ _loadWithCache       │
                    └──────┬──────────────┘
           ┌───────────────┼───────────────┐
           ▼               ▼               ▼
       app.js          router.js        pages/*.js
    (入口+事件)      (路由+切换)    (各页面渲染)
```

**无循环**。core.js 不 import 任何业务模块。

## 改动清单

| 文件 | 动作 |
|------|------|
| `core.js` | **新建** — 共享状态+工具函数 |
| `app.js` | 改 — 删除共享代码，import from core.js；保留 `_getStockList`/`_initSearchSuggestions`/`disposePage` |
| `router.js` | 改 import: `app.js` → `core.js` (state/updateState/showStatus) |
| `pages/dashboard.js` | 改 import: `app.js` → `core.js` |
| `pages/opportunities.js` | 同上 |
| `pages/settings.js` | 同上 |
| `pages/watchlist.js` | 同上 |
| `pages/stock.js` | 分流: core.js (通用) + app.js (stock 专用) |
| `index.html` | 加 `<script type="module" src="js/core.js">` 在所有模块最前面 |
