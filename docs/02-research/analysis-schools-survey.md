# A股分析模型流派全景调研

> 2026-07-04 系统调研

## 技术分析流派

### Wyckoff（威克夫）— A股适用性 5/5
- 三大定律：供求/因果/努力vs结果
- Phase A-E 吸筹模型：SC→AR→ST→Spring→SOS→LPS
- Spring = A股最经典的庄股吸筹信号

### VSA（量价分析）— A股适用性 4/5
- Tom Williams 发展自 Wyckoff，比裸成交量更精确

### Volume Profile — A股适用性 4/5
- VAH突破次日续涨概率 62%，月线POC支撑有效性 65-70%
- LVN加速效应 58% 比 HVN 更可靠
- 九坤/幻方已纳入因子模型

### SMC/ICT — A股适用性 1/5
- FVG回补率仅 55-58%，无独立预测力
- Killzone时间框架完全不适用A股时段

## 基本面流派

### Buffett/芒格 — 100分A股评分卡
- 五维评分：财务质量35 + 护城河25 + 安全边际20 + 管理层10 + A股特别因子10
- A股三大修正：8项财报预警 + 政策风险三维 + 行业PE阈值表
- 芒格15项心智模型清单

### CANSLIM（欧奈尔）— 成长股
- 七维评分：C(当季EPS)+A(年度EPS)+N(新事物)+S(供需)+L(龙头)+I(机构)+M(大盘)

### Graham — 深度价值
- Graham Number = sqrt(22.5 * EPS * BVPS)
- A股局限性：极少出现Graham标准的深度价值股

## 量化/ML流派

### 多因子
- Fama-French五因子→六因子(加MOM)→q^5模型
- Barra CNE6：中国事实标准
- A股本土化最强因子：反转、换手率、流动性

### 机器学习
- GBDT是绝对主力（95%+机构），不是深度学习
- LLM选股是2024-2025最热方向

## 六层融合框架（谛听采用）

```
①基本面筛子：Buffett/芒格 100分评分卡
②估值筛子：安全边际（PE/PB分位+DCF折扣）
③技术面确认：Wyckoff阶段识别 + RS强度
④信号处理：VMD周期位置 + RSI体制判断
⑤择时执行：三维择时（大盘×行业×个股评分）
⑥风险控制：芒格反向清单 + 相关性 + 止损
```
