## A股三大修正

### 1. 财报 8 项红色预警（一票否决）

| 信号 | 阈值 |
|------|------|
| 经营现金流/净利润 | <0.5 |
| 应收账款增速 vs 收入增速 | >1.5x |
| 存货增速 vs 收入增速 | >1.5x |
| 商誉/净资产 | >30% |
| 大股东质押比例 | >50% |
| 非经常损益/净利润 | >30% |
| 审计意见 | 非"标准无保留" |
| 关联交易收入占比 | >30% |

≥3 个 → 一票否决（总分=0）

### 2. 行业PE安全边际阈值

| 行业 | 买入PE | 卖出PE |
|------|--------|--------|
| 消费龙头 | <20x | >35x |
| 金融(银行) | <6x | >12x |
| 科技成长 | <30x | >60x |
| 医药健康 | <25x | >50x |
| 制造业 | <15x | >30x |

## 芒格 15 项心智模型清单

心理学(3项)、经济学(3项)、数学(3项)、生物学/工程学(3项)、反向思考(3项)

每个"是"+0.5分，每个"否"-1分，总分上限+5分。

## 六层融合框架

```
①Buffett/芒格 100分评分卡 → 选股池(5000+→200-300)
②Graham安全边际 → 设定买入价格区间
③Wyckoff阶段识别 → 确认入场时机
④VMD周期位置 + RSI体制判断 → 信号去噪
⑤三维择时(大盘×行业×个股) → 仓位管理
⑥芒格反向清单 + 持仓相关性 → 风险控制
```
