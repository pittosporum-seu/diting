# 威克夫方法（Wyckoff Method）在A股中的应用

> 来源：2026-07-04 深度调研，综合 WyckoffAnalytics、闽发论坛、雪球、GitHub 等

## 三大定律

| 定律 | 核心 | A股实战信号 |
|------|------|-----------|
| 供求定律 | 供>需→跌，需>供→涨 | 缩量下跌=供应枯竭，即将反弹 |
| 因果定律 | 吸筹区间宽度决定涨幅 | "横有多长，竖有多高"的量化版 |
| 努力vs结果 | 量价背离=趋势反转 | 放量不涨=主力出货；缩量不跌=主力吸筹 |

## 吸筹区间 Phase A-E

```
Phase A: 下跌停止 → SC(卖出高潮) + AR(自动反弹)
Phase B: 横盘蓄力 → ST(二次测试，不创新低)
Phase C: 震仓洗盘 → Spring(挖坑/假跌破) ← A股最经典信号！
Phase D: 突破确认 → SOS(强势信号) + LPS(最后支撑)
Phase E: 趋势启动 → 脱离区间，进入 Markup
```

**Spring（弹簧）= RSI超卖 + 缩量后放量收回**，比裸用RSI多了2-3层过滤。

## 与现有体系对接

| 方法 | Wyckoff 对应 | 融合效果 |
|---------|-------------|---------|
| RSI超卖抄底 | Spring确认 | 等缩量→放量→Spring→确认四步走完 |
| VMD谷底 | 吸筹区间末端 | VMD谷底+Phase C=最强买点 |
| DDX资金面 | VSA量价分析 | Wyckoff+VSA=最底层量价逻辑 |

## 学习方法论

| 阶段 | 建议 |
|------|------|
